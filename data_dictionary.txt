# 変数一覧（データ辞書）

## 基本事項

- データ出所：農林業センサス、GISデータ、復興事業関連資料
- 対象年次：2010年、2015年、2020年、2025年
- 年次別変数には `_2010`、`_2015`、`_2020`、`_2025` の
  接尾辞が付くが、以下の対応表では省略する。

## 1. 地域識別変数

| 変数名       | 意味             | 備考                                   |
| ------------ | ---------------- | -------------------------------------- |
| KEY          | 地域識別キー     | データ結合用                           |
| pref_code    | 都道府県コード   | 宮城県は04                             |
| city_code    | 市区町村コード   |                                        |
| kcity_code   | 旧市区町村コード |                                        |
| village_code | 農業集落コード   |                                        |
| area_code    | 地域コード       | 市区町村コードと旧市区町村コードの連結 |

## 2. 農地面積・津波被災関連変数

| 変数名                 | 意味             | 単位 |
| ---------------------- | ---------------- | ---- |
| farmland_total_ha      | 震災前農地面積   | ha   |
| tsunami_total_ha       | 津波被災農地面積 | ha   |
| tsunami_farmland_share | 津波被災農地割合 | 0～1 |

### 備考

- 農地面積は2009年の国土数値情報の土地利用データに基づく。
- 農地には「田」と「その他の農用地」の両方を含む。
- 津波被災農地面積は農地と津波浸水範囲の重複部分の面積。
- 津波被災農地割合は津波被災農地面積を震災前農地面積で
  除したもの。

- 年次間比較の際には面積規模区分の違いに注意する。

## 4. 農業用機械所有関連変数

対象年次：2010年、2015年

| 変数名                | 意味                   | 単位   |
| --------------------- | ---------------------- | ------ |
| transplanter_entities | 動力田植機所有経営体数 | 経営体 |
| transplanter_units    | 動力田植機所有台数     | 台     |
| tractor_entities      | トラクター所有経営体数 | 経営体 |
| tractor_units         | トラクター所有台数     | 台     |
| combine_entities      | コンバイン所有経営体数 | 経営体 |
| combine_units         | コンバイン所有台数     | 台     |

### 備考

- 販売農家に限定せず、農業経営体全体を対象とする。
- 農業用機械所有に関する調査項目は2020年以降の
  センサスでは削除されている。

## 5. 復興事業関連変数

| 変数名             | 意味                         | 備考                             |
| ------------------ | ---------------------------- | -------------------------------- |
| c_one              | C-1事業実施ダミー            | 農山漁村地域復興基盤総合整備事業 |
| c_four             | C-4事業実施ダミー            | 被災地域農業復興総合支援事業     |
| production_support | 生産対策交付金事業実施ダミー | 農業用機械導入                   |

### 備考

- 事業実施地域を1、非実施地域を0とするダミー変数。
- 事業規模、事業費、対象農地面積、支援対象経営体数などの
  情報は含まれていない。
- 地域単位での復興事業への曝露を示す変数として扱う。

## 6. 組織形態別経営体数

対象年次：2010年、2015年、2020年、2025年

| 変数名 | 意味 |
| --- | --- |
| type_total | 農業経営体総数 |
| type_corporate | 法人化している経営体数（計） |
| type_agricultural_corporation | 農事組合法人数 |
| type_company | 会社数（小計） |
| type_stock_company | 株式会社数 |
| type_partnership | 合名会社・合資会社数 |
| type_llc | 合同会社数 |
| type_mutual_company | 相互会社数 |
| type_association | 各種団体数（小計） |
| type_agricultural_coop | 農業協同組合数 |
| type_forestry_coop | 森林組合数 |
| type_other_association | その他の各種団体数 |
| type_other_corporate | その他の法人数 |
| type_public | 地方公共団体・財産区数 |
| type_noncorporate | 法人化していない経営体数（計） |
| type_individual | 個人経営体数 |
| type_voluntary_group | 任意団体数 |

### 集計区分の階層構造

- 農業経営体総数（type_total）
  - 法人化している（type_corporate）
    - 農事組合法人（type_agricultural_corporation）
    - 会社（type_company）
      - 株式会社（type_stock_company）
      - 合名・合資会社（type_partnership）
      - 合同会社（type_llc）
      - 相互会社（type_mutual_company）
    - 各種団体（type_association）
      - 農協（type_agricultural_coop）
      - 森林組合（type_forestry_coop）
      - その他の各種団体（type_other_association）
    - その他の法人（type_other_corporate）
  - 地方公共団体・財産区（type_public）
  - 法人化していない（type_noncorporate）
    - 個人経営体（type_individual）
    - 任意団体（type_voluntary_group）

### 備考

- 単位はすべて経営体。
- 上位区分と下位区分が混在しているため、単純に合計すると
  二重計上が生じる。
- 地方公共団体・財産区は独立した集計区分である。
- entities_totalとtype_totalは異なる集計表に由来する
  農業経営体総数。
- センサスの年次によって組織形態の分類や定義が異なる
  可能性があるため、年次間比較の際には注意する。

## 7. 分析用派生変数

| 変数名              | 意味                                       | 算出方法                               |
| ------------------- | ------------------------------------------ | -------------------------------------- |
| combine_share       | コンバイン所有経営体割合                   | combine_entities / entities_total      |
| tractor_share       | トラクター所有経営体割合                   | tractor_entities / entities_total      |
| transplanter_share  | 動力田植機所有経営体割合                   | transplanter_entities / entities_total |
| gap_tractor_combine | トラクターとコンバインの所有経営体割合の差 | tractor_share - combine_share          |

### 備考

- 現時点では2010年の機械所有割合のみ作成している。
- 算出方法および割合の単位についてはRコードで確認する。
